Tokens are language codes or orig (the title's original language). orig only wins when the original is one of the languages you understand; otherwise the next token (a dub) is used. Default orig,te,en = "original if I understand it, else a Telugu dub, else English". Note this order is global, so a non-understood original (say Korean) prefers a Telugu dub over English — use orig,en to always fall back to English instead.
